# 01. Границы MVP

## Цель MVP

Проверить рабочую систему на 8 ячейках:

- RFID-авторизация;
- открытие ячейки по правам;
- учет остатков;
- пополнение;
- выдача;
- история;
- запрет одновременного открытия нескольких ячеек;
- ручное подтверждение закрытия.

## Входит в MVP

### Пользователи и RFID

- Создание пользователей.
- Привязка RFID UID.
- Блокировка пользователя.
- Авторизация по RFID.
- Отклонение неизвестного RFID.

### Товары

- Создание товара.
- Редактирование товара.
- Поиск по названию.
- Поиск по SKU.
- Поиск по штрихкоду.
- Просмотр общего остатка.
- Просмотр ячеек, где лежит товар.
- Просмотр истории по товару.

### Ячейки

- Справочник ячеек.
- Статусы ячеек: `active`, `blocked`, `maintenance`.
- Привязка ячейки к контроллеру и каналу реле.
- Просмотр содержимого ячейки.

### Остатки

- Учет количества товара по ячейкам.
- Один товар может быть в разных ячейках.
- В одной ячейке может быть несколько товаров.
- Изменение остатка только через подтвержденные операции.

### Операции

- Пополнение товара: `fill`.
- Выдача товара: `take`.
- Открытие без изменения остатка: `open_only`.
- Инвентаризация: `inventory`.
- Отмена операции без изменения остатка.

### Сессии открытия

- Создание сессии перед открытием ячейки.
- Состояние активной сессии сохраняется в БД.
- При перезапуске backend активная сессия не удаляется автоматически.
- Вторая сессия не создается, если уже есть активная.

### Журналы

- Авторизация RFID.
- Неизвестный RFID.
- Отказ в доступе.
- Успешное открытие ячейки.
- Ошибка открытия ячейки.
- Подтверждение закрытия.
- Завершение сессии.
- Отмена сессии.
- Старт системы.

### UI

- Терминальный интерфейс для пользователя склада.
- Минимальная админ-панель.

### Оборудование

- Mock-контроллер для разработки.
- Реальный контроллер через USB-реле или RS485-реле.
- Импульс открытия замка 0.5-1 сек.

## Не входит в MVP

- Согласование выдачи.
- Лимиты выдачи.
- Онлайн-интеграция с внешними системами.
- Мобильное приложение.
- Сложная аналитика.
- Автоматическое распознавание товара через RFID-метки на каждом товаре.
- Обязательные датчики закрытия ячейки.
- Камеры, весы, компьютерное зрение.
- Мультисклад.
- Одновременная работа нескольких терминалов.

## Должно быть предусмотрено на будущее

- Расширение до 50 ячеек.
- Датчики закрытия.
- Интеграционный API.
- Экспорт данных.
- Импорт номенклатуры.
- Несколько контроллеров реле.
- Modbus RTU по RS485.
- Более строгая модель прав.
- Аварийное завершение зависшей сессии администратором.

## Критерий готовности MVP

MVP готов, когда можно выполнить полный цикл:

```text
RFID -> найти товар -> выбрать операцию -> открыть ячейку -> закрыть ячейку -> подтвердить -> получить корректный остаток и историю
```

И при этом невозможно открыть вторую ячейку до завершения первой операции.
