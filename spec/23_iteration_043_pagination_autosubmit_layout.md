# Iteration 043: auto-submit пагинации и выравнивание выбора размера

Дата: 2026-06-17

## Требования

- На `/admin/products?view=products` выбор размера страницы должен быть слева над кнопками `Назад` / `Вперед`.
- При выборе размера страницы список должен обновляться сразу, без отдельного нажатия `Показать`.

## Реализация

- Селектор `На странице` для товаров вынесен из сетки фильтров в отдельную строку перед счетчиком и кнопками пагинации.
- Такой же auto-submit добавлен всем существующим селекторам размера страницы в админке и терминальных списках остатков.
- Фильтры товаров и групп сохраняются скрытыми полями при смене размера страницы.

## Проверки

- UI-тест товаров проверяет наличие `onchange="this.form.submit()"` и положение селектора до счетчика страницы.
