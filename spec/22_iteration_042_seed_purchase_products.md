# Iteration 042: seed-товары из покупок 2026

## Задача

Добавить в команду seed реальные компактные товары из файла покупок `2026.xlsx`, чтобы тестовая база наполнялась более похожими на рабочий склад позициями.

## Реализация

- Расширен `app.seed`:
  - добавлены товары из покупок 2026;
  - добавлены категории для этих товаров;
  - добавлены стартовые остатки в свободные ячейки 2-8.
- Seed остается повторно запускаемым:
  - товары создаются по уникальному SKU;
  - остаток создается только если целевая ячейка свободна.

## Ограничение

MVP рассчитан на 8 ячеек, а одна ячейка может содержать только один товар с положительным остатком. Поэтому все выбранные товары добавляются в справочник, но стартовый остаток создается только для семи новых товаров плюс существующий `HDMI-2M`.
