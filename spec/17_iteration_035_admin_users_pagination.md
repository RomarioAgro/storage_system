# Iteration 035: список пользователей в админке

Дата: 2026-06-17

## Требования

1. На странице `/admin/users` таблица пользователей не должна иметь отдельный столбец `Редактирование`.
2. Редактирование пользователя открывается кнопкой `Редактирование` в столбце `Действие`.
3. Список пользователей поддерживает пагинацию с размерами страницы `10`, `20`, `50`.

## Реализация

- Используется существующая `_admin_pagination`.
- Форма редактирования перенесена в модальное окно по аналогии с товарами и группами.
- Создание, обновление и блокировка пользователей не меняют свои POST-контракты.

## Проверки

- `tests/test_admin_ui.py` покрывает отсутствие отдельного столбца редактирования, кнопку редактирования и пагинацию пользователей.
