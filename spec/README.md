# Локальная RFID-система хранения: пакет ТЗ для команды

Версия: `team_v1`  
Назначение: передать проект в разработку нескольким исполнителям или агентам.

## Кратко

Нужно разработать локальную адресную систему хранения для небольшого офисного склада мелких товаров.

Система должна:

- авторизовывать пользователя по RFID;
- проверять права доступа;
- открывать электронные замки ячеек;
- учитывать товары, ячейки и остатки;
- хранить историю движений по каждому товару;
- вести технический журнал доступа и событий;
- работать локально без интернета;
- поддерживать MVP на 8 ячеек;
- предусматривать расширение до 50 ячеек;
- предусматривать будущие датчики закрытия ячеек;
- предусматривать будущую интеграцию с внешними системами.

## Главное правило безопасности

В один момент времени может быть открыта только одна ячейка.

Новая ячейка не должна открываться, пока текущая операция не завершена:

```text
ячейка открыта
-> пользователь выполняет действие
-> пользователь закрывает ячейку
-> подтверждает закрытие
-> подтверждает или отменяет операцию
-> только после этого можно открыть следующую ячейку
```

В MVP закрытие подтверждается вручную кнопкой `Ячейка закрыта`.

В будущем подтверждение закрытия можно заменить или дополнить датчиками: геркон, концевик, микропереключатель.

## Рекомендуемый порядок разработки

1. Спроектировать БД и enum-статусы.
2. Реализовать backend-ядро: пользователи, роли, товары, ячейки, остатки.
3. Реализовать `LockController` и mock-режим.
4. Реализовать сессии открытия ячеек.
5. Реализовать операции `fill`, `take`, `open_only`, `inventory`.
6. Сделать терминальный UI.
7. Сделать минимальную админ-панель.
8. Покрыть критичные сценарии тестами.
9. Подключить реальное релейное оборудование.
10. Провести приемку MVP на 8 ячейках.

## Базовый стек

Backend:

- Python 3.12+;
- FastAPI;
- SQLAlchemy 2.x;
- Alembic;
- PostgreSQL для боевого запуска;
- SQLite допустим для ранней разработки;
- Pydantic;
- Uvicorn;
- pytest.

Frontend MVP:

- Jinja2;
- HTMX или простой HTML/JS;
- локальный браузер в kiosk mode.

Аппаратная часть:

- USB RFID-считыватель;
- 12 В электромеханические шкафные замки;
- USB или RS485 релейный модуль;
- отдельный блок питания 12 В;
- в будущем датчики закрытия.
