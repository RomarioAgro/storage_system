# Iteration 041: описания разделов админки

Дата: 2026-06-17

## Требования

Внутри каждого раздела админки нужно кратко объяснить:

- для чего предназначен раздел;
- что в нем можно сделать.

## Реализация

Короткие пояснения добавлены в шаблоны:

- `Пользователи`;
- `Роли`;
- `Товары и группы`;
- `Ячейки`;
- `Журналы и сессии`;
- `Остатки`;
- `Оборудование`.

## Проверки

- UI-тесты проверяют наличие ключевых пояснений на страницах админки.
