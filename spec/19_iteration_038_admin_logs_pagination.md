# Iteration 038: пагинация журналов и сессий

Дата: 2026-06-17

## Требования

В `/admin/logs` нужна пагинация 10, 20, 50 записей на странице для вкладок:

- `История движений`;
- `Журнал доступа`;
- `Сессии открытия`.

## Реализация

- Используется существующая `_admin_pagination`.
- Для каждой вкладки добавлен выбор размера страницы.
- Ссылки `Назад` / `Вперед` сохраняют текущий `view` и `page_size`.
- Лимит `50` в запросах журналов убран, так как теперь выдачу ограничивает пагинация.

## Проверки

- `tests/test_admin_ui.py` покрывает пагинацию трех вкладок `/admin/logs`.
