## Epic 2. База данных

### P0. Реализовать модели SQLAlchemy

Модели:

- `User`;
- `Role`;
- `Controller`;
- `Cell`;
- `Product`;
- `StockItem`;
- `StockMovement`;
- `AccessEvent`;

### P0. Реализовать seed-данные

Создать:

- роли;
- admin-пользователя;
- тестовых пользователей;
- 8 ячеек;
- mock-контроллер;
- несколько тестовых товаров.

### P0. Добавить ограничения целостности

- `UNIQUE(rfid_uid)`;
- `UNIQUE(cell_id, product_id)`;
- `quantity >= 0`;
- `UNIQUE(number)` для ячеек;
- partial unique index для активной сессии.

### P0. Стандартизировать timestamps

- использовать timezone-aware UTC во всех ORM timestamp-полях;
- хранить PostgreSQL timestamps как `TIMESTAMP WITH TIME ZONE`;
- нормализовать SQLite dev/test значения в aware UTC на уровне ORM;
- покрыть timestamp lifecycle и API-сериализацию тестами.

### P0. Локальное время административных журналов

- добавить настройку локального часового пояса объекта, по умолчанию
  `Europe/Moscow` / `UTC+03:00`;
- хранить `access_events.created_at` в UTC;
- хранить `stock_movements.created_at` и timestamps `cell_sessions` в UTC;
- отображать журнал доступа, историю движений, сессии открытия, фильтры и
  экспорт в локальном времени;
- покрыть преобразование UTC -> локальное время и фильтры периода тестами.

### P0. Добавить PostgreSQL CI

- поднять PostgreSQL service container в GitHub Actions;
- запускать `alembic upgrade head` на PostgreSQL;
- запускать `pytest` с `POSTGRES_TEST_DATABASE_URL`;
- запускать `ruff check .` перед тестами.

## Предлагаемые этапы

### Этап 1. Backend skeleton

Результат: проект запускается, БД мигрирует, есть seed.

### Этап 2. Core domain

Результат: пользователи, роли, товары, ячейки, остатки.

### Этап 3. Sessions and operations

Результат: fill/take/open_only работают через mock-контроллер.

### Этап 4. Terminal UI

Результат: пользователь может выполнить операции через экран склада.

### Этап 5. Admin MVP

Результат: можно управлять пользователями, товарами, ячейками и смотреть историю.

### Этап 6. Hardware integration

Результат: реальный замок открывается по команде.

### Этап 7. Acceptance

Результат: пройдены тест-кейсы MVP.
