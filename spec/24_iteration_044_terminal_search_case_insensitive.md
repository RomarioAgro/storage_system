# Iteration 044: поиск товара без учета регистра

Дата: 2026-06-17

## Требования

На `/terminal/search` поиск товара должен работать без учета регистра.

## Реализация

- Поиск по штрихкоду, SKU и названию сравнивает нижний регистр значения из базы и строки запроса.
- Порядок поиска сохранен: штрихкод, SKU, затем название.

## Проверки

- UI-тест терминала проверяет поиск в нижнем регистре по SKU, штрихкоду и части названия.
