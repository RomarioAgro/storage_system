# Iteration 036: роли и права в админке

Дата: 2026-06-17

## Требования

1. На странице `/admin/users` нужна кнопка `Роли`.
2. Страница ролей должна позволять:
   - создать роль;
   - редактировать роль;
   - назначить пользователя в роль;
   - назначить права роли списком чекбоксов.
3. Права должны распространяться на пользователей через их роль.
4. Модель прав берется из существующей матрицы ролей.

## Реализация

- Добавлена страница `/admin/roles`.
- В `roles` добавлено поле `permissions` JSON.
- `PermissionService` сначала использует права из роли, а для старых ролей без JSON-прав оставляет fallback на прежнюю матрицу.
- `Role.code` переведен на строку, чтобы можно было создавать новые роли без расширения enum.
- Добавлена миграция `0008_role_permissions`.

## Проверки

- Тесты покрывают создание, редактирование роли, назначение пользователя роли и применение прав в терминальном меню.
